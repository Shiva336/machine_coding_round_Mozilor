MACHINE TEST - FULL STACK DEVELOPER
Create a very basic app where the user can enter a URL and the app will fetch all images from that page,
check which images have alt text and which do not, and then display the results.
Requirements:
1.​ Register and sign in forms. Use JWT or similar token based auth.
2.​ Once logged in the user will enter a URL in an entry box, fetch the content from that URL, extract
all images, and check which ones have a valid alt attribute and which do not.
3.​ Save the URL, total number of images, count of images with alt, and count of images missing alt
in the database along with the scanned user and time.
4.​ Create a graph or chart to show this data – You can choose the chart design as per your
imagination.
5.​ If you have time then add any feature to this app that you think will improve the user experience
or will be useful to the user.
6.​ Usage of AI tools is encouraged and appreciated during development, but you should be able to
explain your code perfectly. And you should be able to explain which AI tool you have used and
purpose.
7.​ Focus more on code quality, security, and app performance. Follow proper coding standards.
8.​ Push your code to a GitHub repository for review.
Please Note:
●​ Design is not important, focus more on UX.
●​ Use any SQL database of your choice. (Preferably PostgreSQL)
●​ Use FastAPI for backend, you can use any available code template or you can build from scratch,
your choice.
●​ Use ReactJS for the front end.
Additional Instructions:
●​ While the time provided is limited, we expect your implementation to reflect production-level
quality in terms of structure, maintainability, and best practices for any functionality you choose to
implement.
●​ You do not need to cover every feature in depth, but whatever you build should be clean, scalable,
and secure.
●​ Pay close attention to code readability, modular design, and API reliability. Assume this is going
into a real-world system.
●​ We value thoughtful engineering decisions over the number of features completed.
